treeview

A two-pane terminal file explorer. Left lists the directory you're in, right previews whatever is highlighted — a folder's contents, or the first 100 lines of a file. Written in Rust on ratatui.

620 KB binary no runtime Linux · macOS MIT

Install

curl -fsSL https://raw.githubusercontent.com/fitri/treeview/main/install.sh | sh
or with Rust: cargo install --git https://github.com/fitri/treeview

Start

treeview              # the current directory
treeview ~/Projects   # a directory you name
treeview ~/.bashrc    # its parent, with the file selected

Keys

h / lfocus the left / right pane
j / kmove the cursor
enteropen the highlighted directory
bksp / -go up one level
/filter the focused pane, live
g / Gfirst / last entry
itoggle Nerd Font icons
.toggle dotfiles
rreload
d / uscroll a text preview
qquit
